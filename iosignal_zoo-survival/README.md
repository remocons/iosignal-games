# 동물원 생존하기 — 아이소메트릭 복셀 멀티플레이 탈출 게임

복셀로 만든 동물원 맵을 여러 참가자가 돌아다니며 살아남는 게임입니다. 스마트폰 참가자는 자기 동물을 따라가는 화면에서 조이스틱으로 움직이고, **점프**와 **지뢰** 버튼을 씁니다. 큰 화면에는 전체 맵을 띄우고, 아두이노(Remocon8266 보드) 참가자는 그 화면을 보며 버튼으로 플레이합니다.

게임 로직은 IOSignal 9.13.0의 **`server.host()`** 로 서버 안에서 돌아갑니다.

## 규칙

- 🏁 맵마다 빛나는 **탈출구**가 있습니다. 가장 먼저 닿은 동물이 **+50점**을 받고, 4초 뒤 모두 **다음 공간**으로 이동합니다. 공간은 1. 동물원 광장 → 2. 악어 늪지 → 3. 로봇 공장 → 다시 1 순서로 돕니다. 탈출과 공간 이동 사이에는 아무도 죽지 않습니다.
- 🐾 동물 8종(병아리, 돼지, 토끼, 판다, 여우, 개구리, 펭귄, 고양이) 중 하나로 입장합니다.
- 💣 **지뢰**를 묻을 수 있습니다(한 번에 3개까지, 1.2초 간격). 0.9초 뒤 무장되며, 무장된 지뢰를 땅에서 밟으면 터집니다. 주인도 예외가 아닙니다.
- ⤴ **점프**(높이 1.7칸, 0.8초)로 지뢰와 폭발, 한 칸짜리 **도랑**, 그리고 **맹수와 로봇**을 뛰어넘을 수 있습니다.
- 💦 **물**(개천, 연못, 도랑)에 빠지면 죽습니다. 다리로 건너세요.
- 😱 **사자, 곰, 고릴라, 경비 로봇, 악어**에게 잡히면 죽습니다. 단, 그 동물보다 높이 뛰어오른 순간에는 넘어갈 수 있습니다(착지 지점이 동물 바로 위면 잡힙니다). 가까이 오면 머리 위에 `!`가 뜹니다. 각자 사는 구역이 있고, 멀리까지는 쫓아오지 않습니다. 악어는 물에서만 움직입니다.
- 🪜 **계단**으로 언덕에 오를 수 있습니다. 한 칸 높이의 절벽은 걸어서는 못 오르고 점프로만 오릅니다.
- 점수: 살아 있는 1초마다 1점, 지뢰로 봇을 잡으면 +5, 다른 참가자를 잡으면 +10. 죽으면 3초 뒤 입구에서 다시 시작하고, 2초 동안 무적입니다. 입구(노란 칸)에는 봇이 들어오지 않습니다.

## 실행

Node.js 22.16 이상이 필요합니다.

```sh
cd iosignal_zoo-survival
npm ci
npm start
```

| 주소 | 용도 |
|---|---|
| `http://localhost:5190` | 참여 화면. 휴대폰은 같은 공유기에서 시작할 때 출력되는 LAN 주소로 접속합니다. |
| `http://localhost:5190/?watch` | 전체 맵(관전). 큰 모니터용. 옆 패널에 **스마트폰 접속 QR 코드**와 주소(이 PC의 LAN IP), 순위, 소식이 나옵니다. |
| `http://localhost:5190/dashboard` | 서버 대시보드(아래) |
| `ws://localhost:5190/ws` | 브라우저용 IOSignal WebSocket |
| TCP `55490` | 아두이노용 IOSignal CongSocket |

혼자 해 볼 때는 봇 참가자를 추가합니다: `npm run bots` (기본 3명) 또는 `node scripts/bots.mjs 5 ws://192.168.0.10:5190/ws`.

포트 변경: `PORT=6000 CONG_PORT=56000 npm start` · 다른 공간에서 시작: `STAGE=2 npm start` (1~3)

### 공개된 곳에서 운영할 때 (제한)

게임 서버는 기본으로 아무것도 제한하지 않습니다(iosignal 10.3.0). 누구나 접속하는 곳에 띄운다면 환경 변수로 제한을 켭니다(`../game-kit/server.mjs`의 `serverLimitsFromEnv`).

```sh
IOSIGNAL_ANON_LIMITS=msgPerSec=100,maxMessageBytes=262144 \
IOSIGNAL_CONNECTION_LIMITS=maxPerAddress=200,newPerAddressPerMin=300 npm start
```

- `IOSIGNAL_ANON_LIMITS`: 로그인하지 않은 연결(플레이어)의 한도. `maxMessageBytes`, `fanout`, `msgPerSec`, `bytesPerSec`, `maxSubscriptions`, `deliveriesPerSec`.
- `IOSIGNAL_CONNECTION_LIMITS`: 공인 주소별 연결 제한. `newPerAddressPerMin`, `failedPerAddressPerMin`, `maxPerAddress`, `msgPerAddressPerSec`, `bytesPerAddressPerSec`. 프록시 뒤에서는 `X-Forwarded-For`의 주소로 셉니다.
- 시작할 때 `Limits` 줄에 적용된 값이 나옵니다.

### 서버 대시보드

`http://localhost:5190/dashboard`에서 서버 상태를 실시간 그래프로 봅니다(iosignal 9.14.0의 `dashboard`). CPU·메모리·이벤트 루프 지연, 트래픽, 게임 호스트의 참가자·초당 입력·위조 차단, 게임 루프의 틱 간격(`host.loop`), 게임 정보(지금 공간, 진행·탈출, 살아 있는 참가자, 지뢰, 봇, 1등)가 나옵니다. 참가자 CID는 앞 두 글자만 보입니다.

- 끄기: `DASHBOARD=off npm start`
- 토큰으로 잠그기: `DASHBOARD_TOKEN=원하는토큰8자이상 npm start` (페이지에서 토큰 입력, 또는 주소 뒤에 `?key=토큰`)

## 조작

| | 이동 | 점프 | 지뢰 | 기타 |
|---|---|---|---|---|
| 스마트폰 | 왼쪽 아래 조이스틱 | 오른쪽 파란 버튼 | 💣 버튼 | 상단 `전체 맵` 버튼으로 시점 전환 |
| PC 브라우저 | 방향키 / WASD (맵 격자 방향) | Space | E 또는 X | M: 전체 맵 ↔ 내 동물 |
| 아두이노 | 네 방향 버튼 (맵 격자 방향) | D6 | D8 | OLED에 상태 표시 |

- 휴대폰 조이스틱은 **화면 기준**입니다. 위로 밀면 화면 위쪽으로 갑니다. 화면을 돌려도 그대로입니다.
- PC 방향키·WASD와 아두이노 버튼은 **맵 격자 방향**입니다. 위 = 화면 오른쪽 위, 오른쪽 = 오른쪽 아래, 아래 = 왼쪽 아래, 왼쪽 = 왼쪽 위(길과 울타리를 따라가는 방향)입니다. PC는 화면을 돌리면 돌린 화면의 격자를 따릅니다. 아두이노는 돌리지 않은 화면 기준입니다.

### 화면 크기와 방향 (마우스)

| 동작 | 마우스 | 버튼(오른쪽 위) |
|---|---|---|
| 확대·축소 | 휠 (커서 위치 기준) | ＋ / － |
| 이동 | 왼쪽 끌기 (전체 맵에서) | |
| 90° 회전 | 오른쪽 끌기 또는 Shift+끌기 (옆으로 90px마다) | ⟲ / ⟳ |
| 처음으로 | 두 번 클릭 | ⌂ |

확대와 방향은 그 브라우저에 기억됩니다. 화면을 돌리면 아두이노 참가자에게는 버튼 방향이 달라 보이므로, 아두이노용 큰 화면은 돌리지 않은 상태(⌂, ⟲⟳로 처음 방향)로 두세요.

## 아두이노 컨트롤러 (Remocon8266 보드, D1 mini)

`arduino/zoo_controller/zoo_controller.ino`. 보드와 버튼 배치는 Remocon 라이브러리 예제 `Remocon8266`을 따릅니다.

| 기능 | 핀 | 연결 |
|---|---|---|
| 위 | D0 (GPIO16) | 보드 SW1, 외부 풀업 |
| 왼쪽 | D3 (GPIO0) | 보드 SW2, 내부 풀업. 전원을 켤 때 누르고 있지 마세요 |
| 아래 | D5 (GPIO14) | 보드 SW3, 내부 풀업 |
| 오른쪽 | D7 (GPIO13) | 보드 SW4, 내부 풀업 |
| **점프** | **D6 (GPIO12)** | 버튼 ↔ GND (내부 풀업) |
| **지뢰** | **D8 (GPIO15)** | 버튼 ↔ **3V3**. GPIO15는 부팅 때 LOW여야 해서 D1 mini에 풀다운이 달려 있습니다. 눌렀을 때 HIGH로 읽으며, GND에 연결하면 동작하지 않습니다. |
| OLED | GPIO4 / GPIO5 | 보드의 SSD1306 (I2C) |
| LED | GPIO2 | 내장 LED (active low) |

1. 라이브러리: IOSignal(9.13.0 이상), Crypto, Bounce2, U8g2. IOSignal 9.x는 Boho 라이브러리도 필요하고, 10.0.0부터는 Boho가 IOSignal 안에 들어 있어 따로 설치하지 않습니다.
2. 보드: `LOLIN(WEMOS) D1 R2 & mini` (`esp8266:esp8266:d1_mini`).
3. 스케치 위의 `WIFI_SSID`, `WIFI_PASS`, `SERVER_HOST`(게임 서버 PC의 LAN IP)를 바꾸거나, 업로드한 뒤 USB로 https://arduino.iosignal.net/wifi/ 에서 넣습니다. 같은 페이지에서 플레이어 이름(`name`)도 정할 수 있습니다. 비우면 `esp-xxxx`입니다.
4. 업로드 후 OLED에 이름과 CID가 나오고 관전 화면에 🔌 참가자가 나타납니다.

```sh
arduino-cli compile --fqbn esp8266:esp8266:d1_mini arduino/zoo_controller
```

OLED에는 `GO!`, `JUMP`, `MINE`, `NO MINE`(지뢰를 묻을 수 없음), `HIT!`(내 지뢰가 터짐), `DANGER`(맹수가 3칸 안), `DEAD 3`(다시 시작까지 초)이 표시되고 내장 LED가 깜빡입니다.

## 구성

```
 휴대폰·PC 브라우저 ── WebSocket /ws ──┐
                                        ├─ IOSignal Server
 Remocon8266 (D1 mini) ── TCP 55490 ───┘        │
                                                └─ 게임 호스트 server.host('zoo') (서버 안)
                                                   · zoo#in 입력 수신 (보낸 CID는 서버가 알려 줌)
                                                   · 20Hz: 이동·점프·물·지뢰·맹수 판정 → zoo#state 스냅샷
                                                   · zoo#$roster 명단(보관), zoo#evt 이벤트
                                                   · 아두이노에는 "@fx" 직접 시그널
                                                   · 연결이 끊긴 참가자는 바로 퇴장
```

- 입력은 호스트에게만 가고, 서버가 확인한 보낸 사람(`from.cid`)이 함께 옵니다. 페이로드에 다른 사람 CID를 넣어 대신 움직일 수 없습니다.
- `zoo#state`, `zoo#$roster`, `zoo#evt`, `@fx`는 호스트만 보낼 수 있습니다. 클라이언트가 보내면 서버가 버립니다(`/healthz`의 `host.denied`).
- 지도는 `public/shared.js`에 있어 서버와 브라우저가 같은 파일을 씁니다. 스냅샷에는 움직이는 것(참가자, 봇, 지뢰)만 담깁니다.

### 통신 프로토콜

| 태그 | 방향 | 페이로드 |
|---|---|---|
| `zoo#in` | 클라이언트 → 호스트 | TEXT `"J,<web\|ard\|bot>,<이름>,<동물 0-7>"`, `"W,<gx>,<gy>"`(맵 격자 방향 -100~100, 브라우저는 보이는 화면 방향을 바꿔 보냄), `"U"` 점프, `"B"` 지뢰, `"H"` 하트비트, `"L"` 퇴장 |
| `zoo#state` | 호스트 → 구독자 | OBJECT `{ t, st(공간), ph('play'\|'next'), nx(다음 공간까지 ms), esc(탈출한 CID), p: [[cid, x, y, z, face, flags, score, life, minesLeft]], b: [[id, type, x, y, face, flags]], m: [[id, x, y, armed, ownerIndex]] }` (좌표는 칸의 1/100) |
| `zoo#$roster` | 호스트 → 구독자 | OBJECT `{ p: [[cid, name, avatar, kind]] }`, 보관 |
| `zoo#evt` | 호스트 → 구독자 | OBJECT `join`, `leave`, `spawn`, `jump`, `mine`, `boom`, `die`(how: mine·drown·caught), `botdie`, `botback`, `escape`, `stage` |
| `@fx` | 호스트 → 아두이노 1대 | TEXT `join spawn jump mine nomine boom die near escape next stage` |

## 예제의 범위

- 상태는 메모리에만 있습니다. 서버를 다시 시작하면 처음부터입니다.
- 익명 접속은 다시 접속할 때마다 CID가 바뀌어 새 참가자로 들어옵니다.
- 호스트는 서버 프로세스 안에서 동작하므로 자기 IOSignal 서버로 실행합니다. 공개 서버(`wss://io.iosignal.net/ws`)에는 호스트를 등록할 수 없습니다.

## 검증 기록 (2026-11-14, iosignal 9.14.0 대시보드)

- iosignal 9.14.0으로 올리고 `dashboard`, `host.loop`(20Hz), `host.report`를 적용. `npm test` 14개 통과(소켓 시험이 `/dashboard`와 호스트 정보 확인). 내장 브라우저에서 봇 4명과 대시보드 확인: 틱 간격 p50 50.8·p99 53.6ms(목표 50), 처리 평균 0.40ms, 입장 이벤트, 참가자 CID 가림.

## 검증 기록 (2026-11-14, 키보드 방향)

- PC 방향키도 아두이노처럼 격자 방향으로 바꿈(`viewToWorld`). 브라우저에서 ↑·→를 눌러 서버 스냅샷 위치를 확인: 돌리지 않은 화면에서 ↑ = y−(오른쪽 위), → = x+(오른쪽 아래), 한 번 돌린 화면에서도 화면상 같은 방향.
