# AI로 게임 만들기

AI 도우미로 IOSignal 멀티플레이 게임을 만들 때 쓰는 자료입니다.

| 파일 | 누구를 위한 것 | 내용 |
|---|---|---|
| [iosignal-game.md](./iosignal-game.md) | AI (영어) | 맥락 파일. 규칙(MUST 8개), 태그 설계, 서버·클라이언트 API, 폴더 구조, 게임 키트, 시험 방법, 흔한 실수, 완료 점검표. AI에게 통째로 줍니다 |
| [prompts.md](./prompts.md) | 개발자 | 단계별 프롬프트 예제: 새 게임(설계 → 규칙·시험 → 서버 → 화면), 싱글 게임을 멀티로, 큰 화면 + 휴대폰 컨트롤러, 아두이노, 봇, 문제 해결, 검토 |
| [../iosignal_star-chase](../iosignal_star-chase/README.md) | 둘 다 | 맥락 파일의 구조 그대로인 가장 작은 게임(약 220줄, 시험 포함). 복사해서 시작합니다 |

맥락 파일은 영어로 썼습니다. AI가 코드와 API를 더 정확하게 읽기 때문이며, 프롬프트는 한국어로 써도 됩니다. `iosignal` 9.23.0 기준입니다.

AI 없이 읽는 설명은 [IOSignal 문서의 게임 절](https://docs.iosignal.net/docs/game)에 있습니다.
