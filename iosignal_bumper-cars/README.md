# 범퍼카 — IOSignal 멀티플레이 범퍼카 게임

놀이공원 범퍼카처럼 쿠션 달린 차를 몰고 서로 부딪치며 노는 게임입니다. 휴대폰이 컨트롤러가 되고, 큰 화면에는 링크 전체와 순위, 접속 QR 코드가 나옵니다. 혼자 타면 봇 차량 2대가 함께 달립니다.

물리와 점수 계산은 IOSignal 9.13.0의 **`server.host()`** 로 서버 안에서 합니다.

## 규칙

- 💥 다른 차에 **부딪치면 점수**. 빠를수록 많고, **옆구리**(×1.5)와 **뒤**(×1.3)를 받으면 더 많습니다. 한 번의 충돌은 최대 20점입니다.
- 🔥 2초 안에 연달아 부딪치면 **콤보**(한 단계마다 +2점, 최대 x9). 내가 받히면 콤보가 끊깁니다.
- 받힌 차는 쿠션에 튕겨 나가고 잠깐 빙글 돕니다(★).
- ⚽ **비치볼**을 차서 다른 차에 세게 맞히면 "슛!" +5점. 🔶 **고깔**을 세게 치면 +1점(고깔은 천천히 제자리로 돌아갑니다). 🟡 **기둥**과 벽은 튕겨 냅니다.
- 🚀 **부스트**: 앞으로 확 튀어 나갑니다(2.5초마다). 📯 **빵빵**: 경적.
- 한 판은 2분이고, 끝나면 1~3등을 7초 동안 보여 준 뒤 점수를 지우고 새 판을 시작합니다.
- 🤖 **봇**은 사람이 딱 1명일 때만 2대 나옵니다. 2명 이상이 되면 모두 나가고, 아무도 없으면 링크가 빕니다.
- 사람과 봇은 한눈에 구분됩니다. 사람 차는 차 색깔의 이름표와 고리(내 차는 흰 이름표·흰 고리와 `▼`)를 달고, 봇 차는 회색빛 차체에 로봇 운전수, 작고 흐린 `🤖` 이름표를 답니다. 순위에서도 봇은 흐리게 보입니다.

## 실행

Node.js 22.16 이상이 필요합니다.

```sh
cd iosignal_bumper-cars
npm ci
npm start
```

| 주소 | 용도 |
|---|---|
| `http://localhost:5192` | 타기(휴대폰). 같은 공유기의 휴대폰은 시작할 때 출력되는 LAN 주소나 큰 화면의 QR로 접속합니다. |
| `http://localhost:5192/?watch` | 큰 화면: 링크 전체, 접속 QR 코드와 주소, 순위, 소식 |

### 서버 대시보드

`http://localhost:5192/dashboard`에서 서버 상태를 실시간 그래프로 봅니다(iosignal 9.14.0의 `dashboard`). CPU·메모리·이벤트 루프 지연, 트래픽, 게임 호스트의 참가자·초당 입력·위조 차단, 게임 루프의 틱 간격(`host.loop`), 게임 정보(경기 중·결과, 남은 시간, 사람·봇 수, 1등)가 나옵니다. 참가자 CID는 앞 두 글자만 보입니다.

- 끄기: `DASHBOARD=off npm start`
- 토큰으로 잠그기: `DASHBOARD_TOKEN=원하는토큰8자이상 npm start` (페이지에서 토큰 입력, 또는 주소 뒤에 `?key=토큰`)

## 효과와 소리

- 충돌: 노란·흰 불꽃, 차가 출렁이는 모션, `+점수`와 `옆구리!`·`뒤에서 쿵!`·콤보 글자(큰 순간에만, 한 번에 10개까지), 내가 부딪치거나 받히면 화면이 살짝 흔들림.
- 부스트 불꽃, 기절 별, 경적 말풍선 `빵!`, 공의 회전, 고깔의 흔들림.
- 소리는 파일 없이 WebAudio로 만듭니다. 고무 공 같은 "보잉"(세게 부딪칠수록 낮게), 짧은 "지직", 공의 "퐁", 고깔의 "톡", 벽의 "쿵", 부스트의 "슝", 귀여운 경적, 콤보 차임, 슛 휘슬, 판 끝 팡파레.
- **시끄럽지 않게:** 전체 음량을 낮게 두고 컴프레서로 묶습니다. 같은 소리는 0.06초 안에 겹치지 않고, 휴대폰에서는 내 차에서 먼 충돌일수록 작게 들립니다. 상단 🔊 버튼으로 끌 수 있습니다(브라우저에 기억). 브라우저 정책상 화면을 한 번 누른 뒤부터 소리가 납니다.

## 구성

```
 휴대폰·PC 브라우저 ── WebSocket /ws ── IOSignal Server
                                           └─ 게임 호스트 server.host('bump') (서버 안)
                                              · bump#in 입력 (보낸 CID는 서버가 알려 줌)
                                              · 30Hz 물리: 차·공·고깔·기둥·벽 충돌, 점수, 봇 운전
                                              · bump#state 스냅샷 15Hz, bump#$roster 명단(보관)
                                              · bump#evt: 한 스텝의 충돌·부스트·경적을 메시지 하나로
```

- 입력은 호스트에게만 가고 서버가 확인한 보낸 사람(`from.cid`)이 함께 옵니다. 다른 사람 차를 몰 수 없습니다.
- `bump#state`, `bump#$roster`, `bump#evt`는 호스트만 보낼 수 있어 점수나 결과를 위조할 수 없습니다.
- 연결이 끊긴 차는 바로 빠집니다.

### 통신 프로토콜

| 태그 | 방향 | 페이로드 |
|---|---|---|
| `bump#in` | 클라이언트 → 호스트 | TEXT `"J,web,<이름>,<색 0-11>"`, `"W,<x>,<y>"`(가고 싶은 방향 -100~100), `"X"` 부스트, `"K"` 경적, `"H"` 하트비트, `"L"` 퇴장 |
| `bump#state` | 호스트 → 구독자 | OBJECT `{ t, ph('play'\|'result'), left(ms), c: [[id, x, y, angle, flags, score, combo, hits]], b: [[x, y, spin]], o: [[x, y, angle]] }` (좌표·각도는 1/100) |
| `bump#$roster` | 호스트 → 구독자 | OBJECT `{ c: [[id, name, color, kind]] }`, 보관 |
| `bump#evt` | 호스트 → 구독자 | OBJECT `{ ev: [...] }`: `hit`(k: car·ball·cone·wall, a, b, x, y, p 세기, pts, where, combo), `shot`, `boost`, `horn`, `join`, `leave`, `round`(ph: end·start, rank) |

## 시험

```sh
npm test
```

- 규칙(11개): 입력, 운전(방향·최고 속도·감속), 부스트 대기, 옆구리 충돌 점수와 튕김, 콤보 누적·받히면 끊김·한 충돌은 한 번만 점수, 벽·기둥 반사, 공 슛, 고깔 제자리 복귀, 봇은 혼자일 때만 2대·사람이 둘이면 퇴장, 판 결과와 점수 초기화, 스냅샷 크기와 시간 초과.
- 실제 소켓(1개): 휴대폰 두 대가 접속해 충돌하고 점수가 오름, 위조한 `bump#state`·`bump#evt`는 전달되지 않음, 페이로드로 남의 차를 몰 수 없음, 접속 주소·QR, 끊으면 바로 빠짐.

## 검증 기록 (2026-11-14, iosignal 9.14.0 대시보드)

- iosignal 9.14.0으로 올리고 `dashboard`, `host.loop`(30Hz 물리), `host.report`를 적용. `npm test` 13개 통과(소켓 시험이 `/dashboard`와 호스트 정보 확인). 내장 브라우저에서 대시보드 확인: 틱 간격 p50 33.8·p99 34.7ms(목표 33), 처리 평균 0.11ms.

## 검증 기록 (2026-11-14, iosignal 9.13.0)

- `npm test` 12개 통과.
- 봇만으로 2분 시뮬레이션: 충돌 213번, 한 번에 평균 9점·최대 19점, 콤보는 대부분 x1~x2(가끔 x3~x4).
- 내장 브라우저: 큰 화면(1400×860)에서 봇 5대 주행·충돌·불꽃·점수 글자·순위·소식·QR, 휴대폰 크기(375×812)에서 입장·키보드 운전·부스트, 콘솔 오류 없음.
- 처음 만든 뒤 봇이 한곳에 몰려 계속 비비며 콤보 x26, 한 번에 +57점이 나오는 문제를 찾아 고침: 충돌 뒤 봇이 잠깐 물러나고 다른 상대를 고르거나 링크 다른 곳으로 이동, 같은 두 차는 0.8초에 한 번만 점수, 콤보는 받히면 끊김, 점수는 덧셈 콤보와 상한 20.
- **소리는 귀로 확인하지 못했습니다**(재생 코드가 오류 없이 도는 것만 확인). 실제 휴대폰 터치로는 해 보지 않았습니다.
